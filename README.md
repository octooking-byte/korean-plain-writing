# korean-plain-writing

할 말은 전부 쓰고, 읽으면 바로 아는 **「한국어 글쓰기 규칙」**입니다.

규칙 전문은 [글쓰기_규칙.md](글쓰기_규칙.md)에 있습니다.

## 이 규칙으로 쓰면 달라지는 점

첫 줄에 답을 씁니다. 본문은 답이 나온 과정을 일이 일어난 순서대로 씁니다.

내용을 줄이지 않습니다. 0번 규칙은 "필요한 내용을 축약, 함축, 절제, 삭제하지 않는다"입니다. 글을 줄이는 대신 보여 주는 방식을 바꿉니다.

ADHD가 있는 사람도 끝까지 읽는 글을 목표로 합니다. 문장 1개에 생각 1개를 쓰고, 문단마다 핵심 낱말을 굵게 강조합니다.

고칠 곳을 세어서 찾습니다. 60자 넘는 문장, 피동, 뜻이 여럿인 낱말처럼 셀 수 있는 기준이 있습니다.

## 규칙의 짜임

규칙은 7개 절, 58개 항목입니다. 7절에는 다 쓴 뒤에 보는 점검 목록 5줄이 따로 있습니다.

1. 쓰기 전에: 전할 내용의 목록, 1문장으로 정리한 요지, 본문보다 먼저 세우는 목차
2. 글 전체의 흐름: 첫 줄은 답, 일이 일어난 순서, 문단 1개에 주제 1개
3. 숫자 · 이름 · 비교 · 앞 문장: 아라비아 숫자, 비교의 대상과 기준, 앞 문장을 가리킬 때 내용을 다시 쓰기
4. 문장 규칙: 주어와 서술어, 맨 동사, 피동과 사동, 합쇼체
5. 낱말 고르기: 사전에 있는 평소 말, 뜻이 여럿인 낱말 피하기
6. 길이와 모양: 문장 길이, 줄 바꾸기, 표와 목록, 강조
7. 다 쓴 뒤에: 점검 목록과 세어 고칠 7가지

## 쓰는 법

1. 사람이 쓸 때는 글을 다 쓴 뒤 7절 점검 목록으로 고칩니다.
2. AI에게 시킬 때는 [글쓰기_규칙.md](글쓰기_규칙.md) 전문을 지시문에 붙여 넣습니다.
